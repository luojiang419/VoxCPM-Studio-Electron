# JVOX Studio 宣传片制作与交付

本片用于闲鱼商品展示和抖音播放，中文解说，围绕原创游戏讲解男声、配音工程和快速入门展开。没有发布到任何平台。

## 交付内容

- 横版：1920×1080、60fps、H.264/AAC，约74.24秒。
- 竖版：1080×1920、60fps，同一条完整旁白，重新安排画面裁切、标题与字幕安全区。
- 48kHz原始完整旁白、独立SRT字幕及实际案例产物。

最终文件保存在项目根目录 `宣传片交付/2026-10-24/`。制作原片、鼠标采样、编辑时间线与机器核验记录保留在 `Electron版本/builds/promo/`，属于本任务材料，不应按普通缓存删除。

## 真实案例与声音来源

旁白484字，通过项目“声音设计”一次提交、一次模型生成，74.24秒。没有上传参考音频，没有使用克隆模式，没有分段生成或拼接旁白。设计描述为：中国青年男性，阳光爽朗，清亮有磁性的中音，标准普通话，专业游戏讲解风格，吐字清晰，语速中快，节奏利落，重点词自然重读，富有感染力但不喊叫。

录屏实际完成声音设计、试听、音色入库、WAV另存为；双角色三句配音、单句重做、整片WAV/SRT/ZIP导出；三条游戏攻略批量生成与归档；作品记录分类；照片说话和视频对口型的真实生成、播放、MP4导出；本地纯音乐生成后在实际软件内试听。LoRA训练未演示。

照片和视频案例使用内置 imagegen 生成的原创虚构青年头像，再由本项目生成口型。头像文件为制作目录内 `虚构青年主持人.png`；提示词要求：虚构24岁中国青年、正面半身、短黑发、自然闭口微笑、海军蓝圆领、米色背景、均匀自然光、无文字/标识/遮挡，不模仿公众人物。原生成图保留在Codex图片目录，项目已保存副本。

背景音乐为本项目ACE-Step 1.5 XL Turbo实际生成的30秒纯器乐《一起开场》。成片低音量混入，并对音乐循环做交叉淡化；完整旁白始终是一条连续声轨，仅做响度处理和编码。

## 录制与剪辑

- 原生1920×1080全屏实际操作，无标题栏与任务栏。F11修复在 `frontend/voxcpm_studio_electron/window-behavior.js`，已实机验证进出全屏及键盘重复事件防抖。
- 经用户明确授权，使用原生Windows脚本替代故障的Computer Use捕获通道。录制输入受到前台进程、窗口归属与尺寸检查约束；记录真实鼠标轨迹，排除非软件窗口时段。
- 原片采集目标60fps，长录制实际为变帧率；先按真实PTS重采样，再对应鼠标轨迹，最终固定60fps输出。不把原片平均帧率当作时间戳使用。
- 根据输入活动切除无操作等待，保留真实结果与播放镜头；鼠标轨迹驱动镜头跟随，重点功能放大，转场使用 `cubic-bezier(.22,1,.36,1)`，快速镜头移动使用三次快门采样模糊。
- 字幕使用已安装SenseVoiceSmall的CTC字词时间戳对齐原始文案，识别文本匹配率98.33%。竖版字幕重新平衡断行，预留右侧与底部显示空间。
