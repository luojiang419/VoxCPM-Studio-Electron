# 唐宫小剧场与软件教程

制作目录：`builds/promo-tang/`。横版原生1920×1080录制，最终60fps；成片时长及交付哈希以 `verification.json` 为准。

结构为10秒唐宫作品预览、真实软件逐页操作教程、79.48秒完整手绘小剧场。片中讲述安禄山在玄宗前胡旋的史载情节，以755年安史之乱作历史回望；具体一场宴会、对白及“最后太平”的视角属于原创演绎，不宣称是可考的最后一宴。史料见 `scripts/promo_tang/plan.json`。

## 声音与真实案例

- 教程793字主讲由本项目声音设计一次提交生成，任务 `ec2e3de45d674a5aa0e83110de9908a4`。最终剪辑在自然章节间插入试听，主讲没有逐句重生成。为阅读节奏使用0.92倍速度，保持音高；CTC匹配97.09%。
- 唐玄宗、安禄山、女乐工、故事旁白均为原创设计音色。克隆案例使用自产虚构女声，不使用演员或公众人物声音。故事对白调用固定角色参考音，避免每句随机设计而换音色。
- 《一曲长安》实际从音乐页面手工中英提示词入口生成，ACE-Step 1.5 XL Turbo，75秒、128BPM、D major。未配置AI助手；不把手工模式冒充AI适配。音乐先在试听段前景展示，再渐退到教程背景。
- 实录包含声音设计、可控克隆、极致克隆、音色库、多角色工程、生成音乐、作品记录、运行控制、资源概览、设置、更新、视频对口型、照片说话和批量；LoRA训练按用户要求跳过。
- 唐宫工程5句4角色实际生成，演示单句重做、加入生成音乐并调至10%、导出WAV/SRT/ZIP；最后导出21.04秒。唐风视频3.36秒与照片2.72秒实际使用LatentSync1.6生成、播放和界面导出。批量3条不同文案已生成并归档。

## 绘图与手绘运动

声音、音乐、口型由当前项目制作；手绘画面独立制作，不宣称软件具有绘画生成功能。插画与原创人物照片使用内置imagegen，落盘 `images/`，未使用CLI或额外API密钥。

提示词方向：唐宫暖金宴会中的胡旋舞、同角色御前邀舞、静谧宫灯庭院、长安灯火全景；统一炭笔线条、水彩、赭黄/朱红/石青。女乐工照片为正面清晰、浅青唐风衣装的虚构人物，供口型驱动。保留各角色身份和衣装，不仿现实演员。

用户引用任务 `01a16769-1d5d-7c92-8142-813ee6545ce9` 已通过read_thread读取。手绘渲染只读调用其本地 `work/leopard-v3/handdraw_motion.py` 和 `work/source/scripts/stream_render.py`；不修改、不复制外部项目源码入仓库。外部依赖路径记录在 `scripts/promo_tang/handdraw.py`。逐笔路径完成线稿后添色，再进入舞袖、灯笼、帷幕和水面的局部运动；预览与运动像素指标在 `handdraw/`。

1. `node scripts/promo_launch.cjs` 启动当前源码；安装模型/运行环境只读复用。
2. `python scripts/promo_tang/common.py` 仅恢复已有语音任务；成功产物不会再次提交。角色正片与实录另保留请求、CTC和工程快照。
3. `python scripts/promo_tang/story_audio.py` 编排完整故事；`python scripts/promo_tang/handdraw.py` 渲染5幕。存在已完成手绘镜头时复用。
4. 原生实录工具 `native.py` 已获用户明确授权。每次输入检查前台进程和原生全屏，记录鼠标轨迹及操作；状态文件仅在变更时原子替换，避免并发读取空文件中断录制。中断的第二段只有47.45秒，后续缺失操作已补录，不使用越界片段。
5. `python scripts/promo_tang/prepare_edit.py` 生成可核对选段；`edit.py --rebuild --proof` 检查合成预览；`edit.py` 渲染正式版；`polish.py` 为试听段加入真实混音频谱、直接展示实际口型成品，并加入0.30秒Bezier章节溶解。频谱明确标注为后期呈现，不冒充软件控件。原片按真实PTS重采样，再对应真实鼠标轨迹。按输入活动剪掉静止等待，并排除无效窗口；镜头使用Bezier缓动，移动时多快门采样形成动态模糊。
6. `python scripts/promo_tang/finish_lipsync.py` 为放大的实际口型成品补上各自台词和真实音频波形；`finalize.py` 完整解码、规格、响度和3秒冻结检测，整理主片与独立手绘小剧场。不覆盖旧版74秒文件。
