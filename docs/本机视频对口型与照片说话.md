# 本机视频对口型与照片说话

本功能使用官方 LatentSync 1.5 权重、256×256 人脸区域和 16 帧时序窗口。默认 20 步、引导强度 1.5，FP16、VAE 分帧和 CPU 人脸检测降低显存占用。主界面的 TTS 依赖和视频依赖分进程使用，生成视频前释放已加载的语音模型；训练或语音识别与视频推理互斥。

## 使用

1. 打开本机版 `VoxCPM Studio.exe`，进入「视频对口型」。
2. 选择已有视频或照片，再选择本地配音、刚生成的声音或配音作品。
3. 视频比配音短时，可循环原片或停在尾帧。点击生成，完成后播放、查看最近作品或另存 MP4。
4. 任务进行中可取消；重新打开页面或重载会恢复当前任务与已保存结果。服务重启后，未完成任务会明确提示失效，已有作品保留。

照片模式保持原照片姿态，驱动嘴部。优先使用单人、正面或轻微侧脸、脸部清晰无遮挡的素材。脸部生成分辨率为 256，原始画面按方向最多保留到横屏 1920×1080、竖屏 1080×1920，不主动放大小素材；最终音轨来自原始配音。

支持 0.32～120 秒配音，长素材建议分段。当前实测为 1.28/1.36 秒短样片，未对 120 秒长片进行性能和内存压测。官方建议至少 8GB 显存；本轮实测为 16GB 的 RTX 4070 Ti SUPER，不把进程峰值当成其他显卡的容量保证。

## 本机模型与安装

当前模型根目录是 `G:/app/VoxCPM-2.0.2/data/lipsync`。在高级参数中可以选择其他完整环境；错误或旧版目录会被拒绝，保留原配置。状态会同时检查 FFmpeg、ffprobe 和 1.5 运行清单，避免将 1.6 权重误标为低显存版本。

源码安装入口在 `Electron版本` 下运行：

```powershell
python scripts/setup_lipsync.py --root ../data/lipsync
```

使用 Windows Python 3.10～3.12，并确保 FFmpeg 和 ffprobe 在 PATH，或放入模型根目录 `tools/`。脚本建立专用 venv，安装固定版本依赖，再下载固定版本源码与权重。`--reuse-installed-torch` 仅用于已有兼容 CUDA PyTorch 的本机开发环境；当前机器采用该模式，未修改主程序 TTS 环境。本轮没有重新下载安装另一套完整的冷环境 CUDA 依赖。

固定来源：

- 源码：`bytedance/LatentSync`，提交 `a229c3948406bc2cf6eaf4873e662e70c6a04746`，使用其中 `configs/unet/stage2.yaml` 的 256px 配置。
- 权重：`ByteDance/LatentSync-1.5`，版本 `32a20d29aead0498e3e885e90dbbe8027da1b61b`，保存到 `source/checkpoints/latentsync-1.5/`，严格匹配加载。
- VAE：`stabilityai/sd-vae-ft-mse`，版本 `31f26fdeee1355a5c34592e401dd41e45d25a493`。Whisper 和人脸检测文件复用已安装资源。

原 1.6 权重保留，原运行清单另存为 `runtime-1.6.json`。推理阶段明确使用本地路径并关闭 Hugging Face 在线下载。模型文件不纳入 Git 或程序包。

## 验证与交付

37 项后端测试通过，其中 14 项覆盖视频服务、真实 FFmpeg 竖屏/循环/停帧/时长/音轨、UTF-8、子进程取消、写入失败回滚、旧模型拒绝和 GPU 互斥，23 项覆盖原配音工作台。

真实源码版 Electron 完成视频和照片生成、播放、中文另存、重载恢复和加载中取消；1544×941、1366×768、1180×760、900×760 的深浅主题检查无窗口溢出。1.36 秒视频生成 37.22 秒，峰值已分配 3287MiB、保留 3494MiB；照片生成 29.78 秒，保留峰值 3498MiB。尾部不足 16 帧的输入正常处理。

本机版目录：`builds/VoxCPM-Studio-2.0.2-LipSync-1.5-Local-20261018`。引用已有运行时、模型和 FFmpeg，适合本机直接运行，不能单独复制 EXE 到其他机器当作完整离线包。验证报告、演示 MP4 和抽帧在 `builds/lipsync-1.5-validation/`。

本机 EXE 也已在实际包含中文和空格的模型目录下完成同样的7组联动和8种布局检查，含照片播放及加载中取消；1.36秒视频37.08秒、照片34.67秒，保留显存峰值3498MiB。中文模型目录中的遮罩、ONNX检测器、UNet和VAE均参与了实际推理，JavaScript异常0。
