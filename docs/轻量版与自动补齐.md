# 轻量版与自动补齐

轻量版保留现有 Electron 工作台。当前r8原生安装器为286720字节，由魔搭补齐桌面壳、依赖及所选模型；也可以分发包含 Electron 的完整轻量 ZIP。用户无需先安装 Python、CUDA Toolkit 或配置命令行。

## 原生轻量安装器

分发 `VoxCPM安装器.exe`（286720字节）或含使用说明的r8 ZIP（225454字节），下载入口见[自动更新说明](自动更新说明.md)。它使用 Windows 10/11 自带的 .NET Framework，不携带浏览器、Python 或模型。点击运行后：

1. 选择安装位置与视频/音乐模型，安装器显示所选组件的容量需求；已有选择与移除状态会保留。
2. 从魔搭下载桌面ZIP，逐文件校验大小和SHA-256，安装到所选目录，并接续依赖及模型补齐。
3. 根据显卡下载对应运行环境，所选组件下载、安装和自检全部完成后再进入工作区。普通依赖使用预先构建的固定wheel集合，音乐使用独立运行包；已有内容校验复用。

原生启动器和桌面补齐器均保留分片续传、缓存校验、损坏恢复；已经完整的桌面文件可直接复用。应用通过自身签名更新器升级后，启动器识别新版版本信息，复用已安装的新版并校验桌面核心，避免将它覆盖回旧内置包。启动器内嵌可信清单，只接受清单中的桌面文件，拒绝 ZIP 路径穿越、重复文件和超出大小的内容，不覆盖 data/models/runtime。

当前r8桌面ZIP为113270602字节（约108 MiB），包含Electron及音乐官方提示词资料，仅保留中英文locale。首次下载和磁盘占用仍然存在，缩小的是用户最初拿到的分发文件。

## 使用流程

1. 解压到可写本地目录，双击 `VoxCPM Studio.exe`。
2. 点击右下角“运行”，或进入“运行控制”点击“运行”。
3. 正常启动显示“音频系统启动中”，按真实阶段展示模型文件检查、音频组件加载与完成状态，复用已安装环境。仅实际缺失或需要更新的组件才显示资源下载/安装提示；下载显示当前文件字节，安装详情可展开日志。
4. 成功后自动连接本地服务。可以暂停，失败后点击“继续补齐并运行”；关闭程序也会暂停。完整文件复用，未完成的直接文件下载保留 `.part` 并尝试 HTTP Range 续传。

首次应预留至少 25 GB 磁盘空间，包含下载缓存、安装后的依赖和模型。模型约 5.9 GB；另有数 GB 的 GPU 运行时。PyPI 依赖由 pip 缓存复用，不承诺所有 pip 下载都有分片续传。补齐完成后，已安装的语音功能可离线使用。

## 显卡与运行时

| 检测结果 | 自动配置 | Windows 驱动要求 |
| --- | --- | --- |
| RTX 50 系、计算能力 10.x 及以上的 Blackwell | PyTorch / torchaudio 2.7.1，CUDA 12.8 | 570.65 或更新 |
| 其余支持的 NVIDIA 显卡 | PyTorch / torchaudio 2.6.0，CUDA 12.6 | 560.76 或更新 |
| 无 NVIDIA 显卡 | PyTorch / torchaudio 2.6.0 CPU | 无 NVIDIA 驱动要求 |

多卡优先选择计算能力最高的一张，通过 `CUDA_VISIBLE_DEVICES` 固定后端使用的设备。旧驱动不支持 `compute_cap` 查询时按型号识别；检测到 NVIDIA 硬件但驱动不可用时提示修复，不误判成无卡。系统驱动需要用户自行更新，程序不会安装或更改驱动。

原默认 `2.6.0+cu126` 构建没有 `sm_120`，`torch.cuda.is_available()` 为真仍可能在首个 kernel 报错。首次完整验证及设备、驱动变化后的复检会实际执行 BF16 张量、矩阵乘法和 SDPA，并同步 CUDA；Blackwell 还检查 CUDA 构建至少为 12.8。环境未变时复用验证结果。RTX 50 系实机仍需单独验收，路由测试不能替代硬件测试。

## 下载源与校验

- Electron 和应用源码：魔搭 `jiangjiang419/voxcpm-studio-updates` 的不可变 `bootstrap/2.0.2/20261018131046/` 路径。启动器内嵌桌面 ZIP 和逐文件哈希。
- 音乐环境：同仓库 `music/20261018-v1/` 的14卷固定资源，共约3.46 GiB，已匿名整文件回读验证。四模型来自清单中的魔搭模型仓库，用户选择安装、移除与恢复；不强制下载全部模型。
- Python 3.12.10、pip、PyTorch / torchaudio：优先魔搭 `runtime/py312-20261018-v1/`，原国内镜像保留为这些基础文件的备用源。固定版本、大小和 SHA-256，不运行远程 `get-pip.py`。
- 普通依赖：157 个固定版本 wheel 全部从魔搭下载并逐文件验哈希，包含传递依赖；客户端通过 `pip --no-index --only-binary=:all:` 本地安装，不访问 PyPI，也不在用户端编译。SymPy 按 torch 配置选取兼容版本。
- 模型：魔搭 `OpenBMB/VoxCPM2`、`iic/SenseVoiceSmall`、`iic/speech_zipenhancer_ans_multiloss_16k_base`。清单固定每个文件的提交地址、大小与 SHA-256。
- FFmpeg：魔搭 wheel 集合中的 `imageio-ffmpeg` Windows wheel 内置可执行文件。

清单随客户端分发，不临时执行魔搭仓库中的安装脚本；模型文件下载到软件根目录 `models/`，不向已有用户配置写入账号信息或代理。客户端匿名下载，不携带发布者Cookie、Token或签名私钥。固定资源使用不可变路径；本次已激活签名应用更新入口，已有用户检查更新并安装后，启动时按原有选择补齐缺失组件。

## 数据与恢复

```text
软件目录/
  VoxCPM Studio.exe
  lightweight.json
  app/                         后端源码
  resources/app/               Electron 前端、补齐器与资源清单
  runtime/managed/py312-cu128/  按设备隔离的 Python 和依赖
  models/                      通过校验的模型
  data/cache/runtime-downloads/ 下载缓存和分片
  data/cache/runtime-bootstrap.log 安装和诊断日志
  data/cache/runtime-ready.json 已验证环境的启动缓存
```

完整便携包启动时也会检查环境：检查通过就复用；检查失败创建独立托管环境，不在旧 Python 或系统 Python 中升级 torch。成功验证后保存启动缓存，后续只做设备识别、关键文件/目录状态和轻量包入口、版本检查，不重复加载全部框架、执行 pip check 或重算数 GB 模型哈希。普通检查不显示首次补齐弹窗。

依赖清单、设备/驱动、路径或关键文件发生变化，包入口/模型缺失、缓存损坏时，缓存失效并重新验证；只有实际需要下载或安装才显示补齐窗口。旧版 ready.json 不会导致重装：首次升级先静默检查实际环境，通过后建立新缓存。应用源码或服务启动错误在服务启动阶段单独报告，不作为重装运行时的依据。失败不标记为可用，重试不用删除整个目录。

Python 核心缺失时恢复核心文件并保留依赖；安装完成但尚未留下 ready 标记时，也先检查实际导入、固定版本和 `pip check`，避免重复安装。中文路径已通过当前进程的 UTF-8 字符 locale 适配。独立更新器可以复用托管 Python；尚未完成第一次补齐时，先运行再安装应用更新。

视频对口型仍使用独立环境及原有安装入口，本次首次补齐覆盖配音、语音识别、降噪及其基础依赖，不自动下载 LatentSync 等大型视频模型。已有的模型路径和自定义配置继续保留。

## 构建

原生启动器先构建桌面包，再将固定桌面清单嵌入 EXE：

```powershell
python Electron版本/scripts/build_lightweight.py --output Electron版本/builds/VoxCPM-Studio-ModelScope-2.0.2-20261018
python Electron版本/scripts/build_bootstrap.py --payload Electron版本/builds/VoxCPM-Studio-ModelScope-2.0.2-20261018.zip --output Electron版本/builds/VoxCPM-Studio-Bootstrap-2.0.2-20261018
python Electron版本/scripts/test_bootstrap.py
```

`modelscope_runtime.py --prepare/--publish` 管理固定依赖资源清单和发布；先准备与检查 wheel 集合，再批量提交，避免并发单文件提交触发魔搭 `commit lock busy`。已发布同名文件必须完全匹配哈希，禁止覆盖；SDK 支持复用已上传内容。`build_bootstrap.py --plan <publication-plan.json> --publish` 发布已构建的桌面和启动器，并匿名完整下载验证。发布凭据只在构建机使用。

在本项目根目录执行：

```powershell
python Electron版本/scripts/build_lightweight.py
# 或
powershell -ExecutionPolicy Bypass -File Electron版本/scripts/build_windows_lightweight.ps1
```

构建会先做 TypeScript 检查和 Vite 编译。前端 `node_modules/electron/dist` 需已安装；开发机可设置 `ELECTRON_MIRROR=https://npmmirror.com/mirrors/electron/` 后执行 `npm ci`。输出默认为 `Electron版本/builds/VoxCPM-Studio-Lightweight-2.0.2/` 及同名 `.zip`。已有输出不覆盖，可通过 `--output` 指定新目录。

轻量包排除系统/便携 Python、CUDA wheel、模型、用户配置、LoRA、输出、缓存及 `node_modules`。完整桌面仍有约百 MB 的运行时体积；原生启动器已将这部分改为首次运行时从魔搭补齐。

## 新界面演示（本地评审版）

原生窗口已采用暖白/深色主题、向量声音波形、分阶段进度和暂停恢复按钮。深浅外观跟随 Windows。新正式 EXE 约 46KB，ZIP 约24KB；尚未替换魔搭线上启动器。

本地 `builds/VoxCPM-Studio-Launcher-Demo/` 中的演示 EXE 可直接体验运行、暂停、继续与完成，不会下载或安装文件。也可以对正式 EXE 使用 `--demo` 参数。

构建时给 `build_bootstrap.py` 增加 `--demo` 可产生独立演示版；使用 `python Electron版本/scripts/render_bootstrap.py` 渲染实际原生界面的8种主题/状态。原生界面源在 `bootstrap/Program.cs`，可视资源由 GDI+ 绘制，无额外图片、字体或浏览器依赖。
