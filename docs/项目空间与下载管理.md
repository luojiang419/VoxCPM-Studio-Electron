当前保留的正式版本是 **2.0.4 / 20261019130543**。正式安装器位于 `builds/正式分发/基准包-2.0.4-20261019130543/`；最新签名更新包在 `builds/updates/2.0.4-20261019130543/`。本次只清理本地文件，未改远端历史、正式版本或用户实际安装。

2026-10-20 清理结果：两轮实际释放约 **88.1 GiB**，项目逻辑文件量约从 **222.1 GiB 降为 64 GiB**，G 盘可用空间约 **136.7 GiB**。剩余 249 个 PYD/DLL 与运行中的 MiniMax/ComfyUI 环境共用硬链接，约 4.15 GiB 逻辑大小、独占文件数据为 0，未终止其他项目；正常关闭占用程序后可再次清理链接。约 2.4 GiB 内容相同的固定安装压缩包原样保留，额外合并操作被自动审批拒绝。

大量空间占用来自：不同版本的安装器与桌面完整副本、多轮隔离安装/升级验证、视频模型与音乐运行包的测试副本、未完成的 Torch 下载，以及 pip 升级后残留的 `~orch` 等目录。模型和 Python/CUDA 依赖单个文件可达数 GB，重复建立测试环境会再次下载、解压并留下副本。部分模型实际是硬链接，文件大小相加会高估物理占用，因此释放空间以清理前后磁盘可用空间差额记录。

## 日常验证与下载

本机已有完整安装，默认从注册表定位 `D:\Program Files\VoxCPMStudio`，直接读取其 `models`、`runtime` 和 `data/lipsync`，无需再次下载或复制模型。前轮留在项目里的资源作为备用，默认调用位置以已安装目录为准。开发入口只读使用安装资源；缺失或校验失败会停止，不会在安装目录内自动修复或删除模型。已有开发配置中的旧模型路径也不能覆盖这一明确绑定。

在前端工程运行 `npm start` 或 `npm run dev`，或在 `Electron版本` 目录执行 `pwsh -File scripts/start_local.ps1`；这些入口使用已安装 Python 运行当前开发源码，开发数据与安装目录分开，保留已有的输出位置设置。安装目录变化后会重新读取注册表；需要指定其他真实安装时，使用 `-InstallRoot '实际目录'`。

在 `Electron版本` 目录执行：

```powershell
pwsh -File scripts/validate_local.ps1
pwsh -File scripts/validate_local.ps1 -Script scripts/smoke_installed_resources.cjs
pwsh -File scripts/validate_local.ps1 -Fixture -Script scripts/smoke_lazy_startup.cjs -ScriptArgs --startup-only
```

入口设置 `VOXCPM_OFFLINE=1`、Hugging Face 离线模式和 `PIP_NO_INDEX=1`。实际资源脚本还设置安装目录对应的模型与环境变量，不复制权重；`-Fixture` 专供隔离测试，使用临时的小文件和模拟服务，不绑定正式安装资源。前轮加入的本地复制逻辑仅用于独立固定安装包/隔离夹具，不作为已安装模型的复用方式。

真实首次安装或网络续传测试需要明确选择联网入口，提前统计缺失文件大小；普通修改不重复做全新 GPU 环境安装。本入口不是网络沙箱；它约束项目资源下载器、Hub 与 pip，不拦截所有业务 API 或第三方脚本的 HTTP 请求。

## 再次清理

```powershell
python scripts/plan_storage_cleanup.py
pwsh -File scripts/cleanup_project.ps1
pwsh -File scripts/cleanup_project.ps1 -Apply
```

先检查预览，再执行；执行前关闭项目进程。清单只包含项目内的历史构建、可再生缓存和冗余资源，执行端拒绝越界和穿过上级 junction 的路径；目录内的链接只删除链接本身。配置另存于被 Git 忽略的 `builds/storage-cleanup/preserved-configs/`，不提交凭据。

清理前统计、计划与实际执行结果分别保存在 `builds/storage-cleanup/before.json`、`plan.json`、`result.json`。不要删除整个 `models`、`runtime`、`vendor` 或上述固定离线资源，否则下一次准备会再次下载。
