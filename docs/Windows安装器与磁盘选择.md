# Windows 轻量安装器

用户只需分发 `VoxCPM安装器.exe`。安装器从魔搭获取桌面包、独立 Python、固定依赖和模型，校验 SHA-256 后安装；模型仍使用魔搭官方仓库。启动器本身不包含 Electron、Python、CUDA 或模型。

## 安装位置

- 自动选择当前用户可读写、剩余空间至少 25 GiB 的非 C 本地固定分区，优先剩余空间最多的分区。
- 磁盘卡片显示盘符、可用空间和不可选原因。点击非 C 盘后默认安装到 `盘符:\Program Files\VoxCPMStudio`，例如 `D:\Program Files\VoxCPMStudio`；需要时创建目录，不能直接安装在磁盘根目录。自动选择也使用同一规则。
- 非 C 盘的 `Program Files` 无读写权限、有目录冲突或空间不足时，跳过该分区。全部不满足条件时自动尝试 C 盘的当前用户专用目录；用户也可手动选择可用的 C 盘。
- C 盘首选 `LocalAppData/VoxCPMStudio`，依次尝试 `LocalAppData/Apps/VoxCPMStudio`、`UserProfile/Apps/VoxCPMStudio`、`UserProfile/VoxCPMStudio`，最后才探测带用户 SID 的 `C:/VoxCPMStudio/用户SID`。只接受 C 盘、空间充足且实际权限探测成功的位置，不扫描整盘，也不使用临时目录或公共共享目录。
- 权限探测实际复制 EXE、独占读写、重命名和删除测试文件；已有卸载器还会检查其是否只读或被占用。不可用候选自动跳过，全部不可用时提示重新选择，不申请管理员权限。支持中文用户名、中文文件夹和空格路径。
- 已完成的安装继续原位恢复，不自动迁移个人数据。保存的未完成安装位置不可写时重新搜索；已完成的位置不可写时明确说明占用或限制，并保留原目录。
- 手动路径仍检查分区、容量、归属和写入权限。已有本产品的准备中/已完成目录可继续恢复，卸载后的重装重新检查容量。
- 所有操作使用当前用户权限，不安装 Windows 系统服务或显卡驱动，不要求管理员权限。

## 界面与图片

`assets/brand/disk-local.png` 为全新薄型机械硬盘透明 RGBA 图片，包含盘片、读写臂、金属底座及柔和投影；安装器内嵌其 256 像素版本。代码生成脚本为 `scripts/build_disk_icon.py`。

选中时图标放大到 117%，同时显示高亮和勾选；切换后原图标复原。悬停、选中、自动横向滚动和准备动画统一使用 `cubic-bezier(0.22, 1, 0.36, 1)`，曲线实现包含 x 的反解。拖动滚动块直接跟随指针。

磁盘区域不启用 Windows 原生横纵滚动条；卡片超宽时仅显示底部自绘横向滚动条，配色跟随深浅主题。支持滚轮、拖动、轨道点击和键盘聚焦后自动滚入视野。

应用和安装器品牌标志由 `scripts/build_brand_icons.py` 生成 SVG、透明 PNG 和多尺寸 ICO；应用 EXE、窗口、快捷方式和应用列表使用相应图标。

## 完成安装与卸载

先在下载桌面包前写入卸载器：相同内容直接复用，新内容使用临时文件和原子替换；短暂占用有限重试，失败保留原文件并说明原因。随后验证桌面、运行环境和 GPU 运算，再启动隐藏的 Electron 窗口。API 与渲染层均就绪后，安装器校验当前会话报告，才创建桌面/开始菜单快捷方式并登记 HKCU 的 Windows 卸载入口。第二次启动显示已准备好的窗口。

2026-10-18 的 r5 使用 Windows SAFER 普通用户令牌，在 C 盘中文和空格路径完整验证：跳过显式拒绝写入目录、创建卸载器、展开应用、GPU/依赖检查、API/renderer 就绪、隔离快捷方式及 HKCU 登记、展示原窗口、卸载保留个人数据全部通过。测试没有管理员权限，不修改系统设置；证据在 `builds/installer-cdrive-validation/standard-user-result.json`。

卸载默认删除应用、下载模型、托管运行时和缓存，保留个人配置、音色、作品和 LoRA；用户明确勾选后才清除个人数据。遇到文件占用时保留卸载入口以便重试；删除过程不递归穿越目录连接。专用归属标记和独占锁防止误接管目录及并发安装。

## 验证与构建

```powershell
python scripts/build_brand_icons.py
python scripts/build_disk_icon.py
python scripts/test_installation.py
python scripts/test_bootstrap.py
python scripts/render_bootstrap.py
```

`render_bootstrap.py` 渲染实际 WinForms 窗口，输出深浅主题、空间不足、多磁盘滚动、运行时长标题/文件名、开关关闭等 18 张预览，以及磁盘缩放和开关光效动图；不下载或安装应用。`build_bootstrap.py --demo` 构建可点击的独立演示 EXE。

`scripts/smoke_installation.py` 可显式验收完整握手，借用 `builds/bootstrap-validation` 中的专用测试运行时和模型，并在隔离快捷方式目录和 HKCU 测试键中完成安装、展示窗口和卸载；测试安装根包含 `Program Files`，同时验证空格路径。大型模型不重复下载，借用的运行时 `_pth` 在结束时恢复，目录连接只移除连接本身。证据为 `builds/installer-live-validation/result.json`。

本机 RTX 4070 Ti SUPER/cu126 已完成真实验收。RTX 50/Blackwell 自动分流 cu128 和最低驱动规则已测试；没有 50 系硬件，尚未实机验收。

## 下载状态与选项开关

进度卡中的长标题/文件名最多占两行，必要时适配字号；标题、说明、百分比、进度条和下载字节使用独立边界并裁切，避免换行重叠。完整状态文本保留在日志及辅助描述。

桌面/开始菜单选项采用带柔和阴影的自绘切换开关，滑块与开启光效同步使用贝塞尔缓动，关闭后光效熄灭；快速反向切换保持连续，禁用时不可改变选项。支持键盘、辅助功能状态和点击。

全部安装器按钮采用 Control + IButtonControl 自绘背景，父背景预合成并以 4 倍超采样处理圆角。右上角关闭/最小化使用同样处理的矢量图形，避免原生 Button 主题白底和字体边缘杂边。20 项安装器测试包含深浅主题及 100/125/150/200% 多尺寸模拟、实际屏幕合成截图和交互行为验证。

安装器默认使用浅色主题，不读取系统深色偏好。右上角太阳/月亮按钮切换显示风格，按钮、磁盘列表/滚动条和开关同步更新，保留目录、选项、进度和滚动位置。超采样图像使用镜像边界，避免浅色主题下出现双三次插值亮边。
