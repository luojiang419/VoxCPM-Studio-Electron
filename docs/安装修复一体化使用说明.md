# 安装修复一体化使用说明

运行同一个 `JVOX Studio配音系统安装器.exe` 即可安装或检查修复。

2026-10-19 最终新安装基准为 `2.0.4 / 20261019122407`，将“功能与模型管理”移至音乐模型面板右上角，替换“自由选择”；包含[退出行为设置](./退出行为说明.md)、后台托盘和深浅主题确认弹窗，并修复关闭结束中进程误报权限不足；保留此前全部应用功能：[从魔搭下载最终基准安装器](https://modelscope.cn/api/v1/models/jiangjiang419/voxcpm-studio-updates/repo?Revision=master&FilePath=installers%2F2.0.4%2F20261019122407-9aa56486a0%2FJVOX-Studio-Installer.exe)（约125.7 MiB）。EXE SHA256：`b46110d3661ed5ad9d9e9a216c54a67c9950b3ff46f0b43f3f90538b6e3d0bad`。分发约定见[分发基准包](./分发基准包.md)。

- 首次安装：选择安装位置和功能，补齐依赖与模型，完成后进入工作台。
- 再次运行：自动识别原安装目录，检查应用、运行环境和已选择的功能。正常时提示“一切正常，无需再次安装，开始创作吧”，可点击“开始创作”。
- 发现问题：显示检查及修复进度，使用可信签名包恢复，完成后再次检查。保留作品、模型、密钥及功能选择。
- 安装中断：再次运行会继续原安装流程。已卸载后再次运行进入安装。

检查正常的安装不会关闭工作台。修复需要关闭本目录的工作台和后台进程，运行安装器前请保存正在编辑的任务。无法修复时窗口显示原因，可通过“查看更新日志”定位；不会把检查失败显示为正常。

单EXE内置桌面程序、签名应用快照和独立修复环境，不需要预先安装Python或开发工具。首次依赖/模型下载，以及获取比内置包更新的修复资源，仍需网络。当前版本高于可用修复包时拒绝降级。

## 开发与构建

`python scripts/build_unified_installer.py` 构建单EXE，只生成本地产物，不发布或激活公网通道。`--snapshot` 用于已有同内容签名快照；安装包与快照逐文件核验，不一致则中止。

已验收产物使用 `python scripts/publish_legacy_repairer.py <签名快照目录> <一体版EXE> --activate` 发布。发布器校验构建和验收记录，按一体版独立不可变路径上传；EXE和应用包均匿名完整回读成功后才切换签名最新入口。去掉 `--activate` 只上传EXE，不激活应用更新。

测试入口：`scripts/test_unified_installer.py`、`tests/test_unified_installer.py`、`scripts/smoke_unified_installer.py`。实机脚本使用隔离注册表/快捷方式目录，复用本机已验证测试依赖与模型；不读取用户密钥。
