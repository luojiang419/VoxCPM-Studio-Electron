## 维护基准

构建时明确指定已验证的签名应用快照，再验收最终 EXE 并冻结分发目录：

```powershell
python scripts/build_unified_installer.py --snapshot <签名快照目录>
python scripts/smoke_unified_installer.py <最终安装器构建记录.json>
python scripts/finalize_distribution_baseline.py <最终安装器构建记录.json> <对应验收报告.json>
python scripts/publish_legacy_repairer.py <签名快照目录> <最终安装器EXE> --activate
```

冻结脚本核对签名、应用包、源码、实际安装目录和桌面包，再复制 EXE 和生成分发说明、SHA256 及基准包记录。已有基准目录拒绝覆盖。普通后续更新沿用应用发布序号；需要重新冻结新安装基准时，以新的签名快照构建新目录，保留历史产物。
