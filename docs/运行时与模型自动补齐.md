# 运行时与模型自动补齐

适用范围：Windows x64 桌面安装版。本文所述修复已随 `2.0.4 / 20261024023545` 发布到魔搭安装器与签名更新包，下载入口见[分发基准包](./分发基准包.md)。

| 显卡 | 主音频运行时 | Windows 驱动下限 | 配音 BF16 权重实际计算精度 |
| --- | --- | --- | --- |
| RTX 20 系 | PyTorch 2.6.0 / CUDA 12.6 | 560.76 | FP32，避开 Turing 不支持的原生 BF16 |
| RTX 30 / 40 系 | PyTorch 2.6.0 / CUDA 12.6 | 560.76 | BF16 |
| RTX 50 系 | PyTorch 2.7.1 / CUDA 12.8 | 570.65 | BF16 |
| 无 NVIDIA GPU | PyTorch 2.6.0 CPU | 不适用 | CPU 路径；音乐/口型功能仍有 GPU 要求 |

首次运行缺少 Python 时自动下载嵌入式 Python、匹配显卡的 Torch/torchaudio 和固定依赖；无需用户自行安装 Python 或 CUDA Toolkit。正常启动会识别显卡、核对依赖版本和 CUDA 构建，并加载 Torch/torchaudio 核心原生库发现缺失 DLL。检查异常时自动进入托管环境恢复，正常启动不校验全部模型、不进行全套 GPU 推理。超时、用户取消和驱动不满足要求不会触发盲目重装。

配音、语音识别与降噪在使用对应功能时校验其模型，缺失或 SHA256 不符时只修复所需文件，成功后继续原请求。整目录缺失的内置 VoxCPM2 也按固定清单恢复。自选的其他模型路径继续由用户管理。音乐在已启用且独立运行时就绪的情况下，生成前自动修复当前模型；未启用模型、独立音乐运行包和视频组件仍按既有功能管理入口准备，尊重用户选择。

有效本地文件复用，下载支持断点续传与最终 SHA256 校验。主运行时、固定依赖、音乐运行包、视频依赖和模型首选来源均为魔搭；官方模型按配置中的固定 revision 获取。驱动更新、网络连接、安装盘可写空间和显存容量仍是运行条件，自动补齐不能修复所有硬件或系统问题。20 系的 FP32 路径比 BF16 使用更多显存，大型音乐/视频模型需要按自身要求选择，不能承诺每张 20 系显卡都能运行所有模型。

开发入口继续只读复用安装目录，资源不齐时报告，不修改正式安装。

## 验证记录（2026-10-24）

- 魔搭匿名核对 229 个独立文件的大小与 SHA256 元数据，全部匹配；cu126/cu128 主 wheel 单字节下载均返回正确 HTTP 206 范围，未重复下载数 GB 大包。报告：`builds/resource-distribution-validation/20261024/report.json`。
- RTX 4070 Ti SUPER 实际执行主运行时矩阵/注意力算子与当前源码配音，生成 48 kHz、2.56 秒有限且非静音 WAV。报告：`builds/gpu-resource-validation/report.json`。
- 同机正常启动路径的实际检查耗时 2806ms，零下载、不扫描模型。报告：`builds/gpu-resource-validation/startup-report.json`。
- 已安装独立音乐运行包实测 PyTorch 2.11.0+cu128，包含 sm_75、sm_80、sm_86、sm_90、sm_100、sm_120。此记录证明运行包包含相关架构内核，不等于已在所有显卡完成各音乐模型推理。
- 20/30/50 系只有路由、修复和精度逻辑模拟回归，无对应实体显卡完整功能验收。后续应补相应设备的实机生成记录，当前发布不宣称已完成这些设备的实测。

复核命令：`python scripts/check_resource_distribution.py --output builds/resource-distribution-validation/20261024/report.json`；离线实机验收：`pwsh -File scripts/validate_local.ps1 -Script scripts/smoke_gpu_resource_runtime.py`。

架构与 CUDA 12.8 的官方背景资料：[NVIDIA Blackwell 迁移指南](https://forums.developer.nvidia.com/t/software-migration-guide-for-nvidia-blackwell-rtx-gpus-a-guide-to-cuda-12-8-pytorch-tensorrt-and-llama-cpp/321330)。实际采用的版本与驱动检查以本项目固定配置及验收记录为准。
