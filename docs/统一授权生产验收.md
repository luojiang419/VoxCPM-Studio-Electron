# 统一授权与试用版生产验收

状态：2026-10-25 已完成单EXE安装包、永久授权自动转正式版及IP/MAC联合防重复试用；历史演示不承担实际授权。

## 运行与使用入口

- 云端管理：`https://admin.ee2x.cn/admin/login`，使用用户指定的初始凭据；后台“账户设置”可修改用户名与密码。
- 部署：腾讯云服务器，目录 `/opt/useradmin`，当前源码 `releases/20261025-v6`，`current`指向该版本。独立`ee2x-auth.service`监听本机4102，HTTPS由1Panel OpenResty代理。
- 软件内：左下角“登录 / 注册”创建或进入账户；已登录后显示用户名与剩余天数，点击“账户与授权”查看倒计时、作者联系方式、刷新授权或退出登录。
- 云端：选择软件/用户→调整试用期限，或核实收款后开通永久权限。新增软件使用独立app_id，账号可共用，授权不相互传递。
- 作者联系方式已按本仓库README公开信息配置；可在“软件接入”修改，不含虚构收款渠道或价格。
