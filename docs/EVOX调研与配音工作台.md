## 本项目的升级方向

将“快速合成一条声音”扩展为“持续制作一个配音项目”。保留原有 VoxCPM 2 本地推理、声音设计、可控/极致克隆、参考音频识别、LoRA 训练、批量任务、资源监控及自动更新。

| 工作阶段 | 新工作流 |
| --- | --- |
| 整理文案 | 粘贴或导入 TXT/SRT，识别 `{角色}`、`角色：台词`，按句子与字数拆分 |
| 分配音色 | 每个角色独立生成模式、控制词、参考声音与 LoRA；音色收藏到本地库 |
| 精修台词 | 增删、复制、排序、调整停顿；逐段生成或重做，参数变化后提示音频过期 |
| 制作整片 | 跳过已有有效片段，失败段落可继续；段间安全停止；按完成段数报告真实进度 |
| 导出作品 | 合成双声道 WAV、真实段长 SRT、逐段及按角色 WAV 与清单 ZIP；支持角色音量/声像、WAV 背景音乐混音 |
| 恢复工作 | 工程、音色和作品记录存入 `data/workspace`，重启后可继续，更新不覆盖 |

界面采用深色炭灰与浅色中性白：固定导航、单行页面大标题与服务状态，中央台词编辑，右侧角色配置和音色应用，底部试听与导出。支持深浅主题与较小的桌面窗口。

这是在现有模型能力上增强制作流程；音色质量仍取决于模型和参考音频，不宣称所有功能或效果全面超过 EVOX。数字人对口型、多角色同时发声、插件市场和额外模型引擎不在本轮交付范围，不提供无功能的入口。

## 后端源码位置

主工程运行源码为 `src/voxcpm/studio_api.py` 与 `studio_workspace.py`。由于 Git 仓库边界位于 `Electron版本`，桌面功能对应后端文件同时维护在 `Electron版本/backend/voxcpm/`；便携打包和热更新构建优先采用该覆盖层，防止只提交前端导致其他机器缺少新接口。

运行开发版本时，应将覆盖层同步到父工程 `src/voxcpm/`，使用现有便携 Python 及本地模型目录。普通用户继续运行根目录 `VoxCPM Studio.exe`。

```powershell
# 在 Electron版本 目录恢复已跟踪的桌面后端
Copy-Item backend/voxcpm/*.py ../src/voxcpm/ -Force
```

## 开始一个配音项目

1. 在「配音工作台」新建项目，点击「导入文案」。例如输入 `{旁白}故事从这里开始。` 和 `{主角}很高兴遇见你。`，点击「整理并导入」。TXT/SRT 文件也可以从导入窗口选择。
2. 在右侧选择角色，设置声音设计、可控克隆或极致克隆。克隆模式选择本地参考音频；极致克隆可填写逐字参考文本，留空时使用原有语音识别能力。
3. 在「声音设计与克隆」中设计或克隆声音，生成并试听后，点击底部「保存音色」，填写名称和标签，保存后自动进入音色库。音色库支持试听、应用到配音角色和「继续设计」创建新版本。试听与参考文件独立归档，移动原输出不会破坏已保存音色；设计出的声音应用到角色时，以保存的声音作为固定参考。调整参数或文案后需重新生成再保存，避免保存结果与配置不一致。旧音色仍可使用。
4. 编辑每段文字与停顿，点击「开始合成」。可以只生成/重做一段；「暂停任务」在当前段完成后停止，已完成的声音保留。
5. 修改文案或音色时，旧声音会标记为待重新生成。全部有效后可以整片试听与导出；WAV、字幕和 ZIP 可另存到指定目录。
6. 角色音量、左右声像和 WAV 背景音乐在导出时混音，不需要重新调用模型。SRT 使用本次实际音频时长，导入 SRT 的原始时间不会强制套用到新音频。

项目会自动保存，浏览器本地草稿为未完成保存提供恢复。断开服务后先恢复服务再继续操作；任务本身是内存队列，重启不会自动继续推理，但已经落盘的片段可继续使用。

段间停顿与音色混音不会改变模型内部发音速度或音高；控制描述是否生效取决于当前 VoxCPM 模型。当前导出格式为 WAV/SRT/ZIP，不会将 WAV 仅改扩展名冒充 MP3。

## 验证入口

```powershell
cd frontend/voxcpm_studio_electron
npm run typecheck
npm run build
npm run test:update
cd ../..
$env:PYTHONPATH = (Resolve-Path ../src).Path
python -m pytest tests/test_studio_workspace.py tests/test_updater.py ../tests/test_studio_api.py -q
```

真实模型测试使用 `scripts/validate_production.py` 连接运行中的本地服务；`scripts/smoke_production.cjs` 检查真实 Electron 界面、导入、复制、试听、导出、保存与重启，可加 `--portable` 验证已接入的便携版。测试工程和报告在 `builds/production-validation/`，不进入用户正式工程目录。
