# 双 CUDA 全量分发包

分发目录：`builds/正式分发/JVOX-全量安装包-2.0.4-20261024/`。

版本为 `2.0.4 / 20261024034042`，包含当前应用功能与本轮运行时选择、自动补齐修复。本包只在本地构建，没有上传约 33GB 的完整资源，也没有替换用户正式安装。

## 如何分发

把整个分发文件夹交给用户，主要文件必须放在一起：

- `JVOX全量安装器.exe`：原生安装界面。
- `JVOX-完整资源.zip`：完整应用、模型和运行环境，约 30.95 GiB（33.24 GB）。
- `SHA256SUMS.txt`、`分发记录.json`、`验证结果.json`：校验与验证信息。
- `分发与安装说明.txt`：用户安装说明。

用户双击安装器，选择安装位置及功能。资源在本地展开，展开内容约 42.75 GiB，安装盘另保留至少 5 GiB 供视频依赖准备与运行。ZIP 大于 4GB，分发介质需支持大文件，例如 NTFS/exFAT。安装完成后运行安装目录中的 JVOX 主程序。

| 内容 | 随包状态 |

运行要求为 Windows 10/11 x64。NVIDIA 驱动分别至少为 560.76（20–40 系）或 570.65（50 系），不需要另外安装 Python 或 CUDA Toolkit。20 系使用 FP32 回退，显存开销更大；各模型仍需符合自身显存条件。

全量包的初装选项会标明“已内置”或“首次需联网”。内置口型为 1.6，初装建议 16GB 显存；较小显存用户可在软件内按需下载 1.5。MiniMax Music 3、YuE2、HeartMuLa、其他未安装模型，以及 CPU 专用环境仍使用原有按需补齐通道。云端功能仍需要用户自行配置账号/API 密钥和网络。

用户作品、API 密钥、账号、个人设置、下载历史、Git、签名私钥及字节码缓存未随包。缺失或损坏资源仍可从魔搭自动补齐，不要求用户手工挑选 CUDA 环境。

## 验证与可恢复构建

独立验收从真实 ZIP64 逐文件校验并解压，随后把应用移到新的中文/空格目录，测试两套运行时、便携命令、实际配音、视频离线依赖与桌面/API。验证记录在 `builds/full-offline-20261024-v1/validation/`，分发摘要在包内 `验证结果.json`。

本机物理显卡为 RTX 4070 Ti SUPER；50 系完成路由模拟、实际 cu128 导入/算子以及 sm_120 内核检查，没有宣称完成 50 系实体显卡全功能测试。

构建入口：

```powershell
# 正式安装位置应由 scripts/installed_resources.ps1 从注册表定位。
python scripts/build_full_distribution.py resources --installed <正式安装目录> --work builds/<新的工作目录>
python scripts/build_full_distribution.py package --work builds/<新的工作目录> --output builds/正式分发/<新的分发目录>
python scripts/smoke_full_distribution.py --work builds/<新的工作目录>
```

资源与压缩完成后，可用 `launcher` 阶段仅刷新原生壳；命令入口发生变化时可用 `consoles` 阶段增量更新 ZIP。刷新后必须更新 SHA256 并重新执行验收。成功交付后可通过项目清理清单移除大型暂存/测试副本，保留分发 ZIP、EXE、签名快照及验证报告；重新构建请使用新的工作目录。
