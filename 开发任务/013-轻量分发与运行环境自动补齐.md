## 目标与方案

保留现有 Electron 界面，轻量包只包含桌面壳、后端源码和补齐逻辑，不包含 Python、CUDA、模型及用户数据。用户点击运行，弹窗展示依赖和模型补齐，完成后自动启动服务。

借鉴 G:/app/minimax 的 aux_runtime.rs：可信清单、大小和 SHA-256 校验、.part 续传、已完成文件复用、错误可恢复。资源优先国内公开源，不要求预先上传私有运行时包。补齐到软件同级独立托管目录，不修改系统 Python 或现有便携运行时。50 系/Blackwell 选择 torch 2.7.1+cu128，其余兼容 NVIDIA 选择 cu126，无 NVIDIA 选择 CPU；驱动不足给出可操作提示，不尝试自动安装系统驱动。先实际运行 CUDA 张量和矩阵运算，再启动服务。

## 安装引导与 Windows 集成

追加目标：让用户选择专用安装目录，安装并补齐环境后再创建桌面/开始菜单快捷方式、登记 Windows 应用卸载入口；提供配套卸载器，默认保留用户数据，可选删除；启动器与应用使用全新透明 PNG/多尺寸 ICO。安装采用当前用户权限和 HKCU 登记，不安装系统服务或显卡驱动。使用会话标识与本地就绪报告确认环境/API/渲染层就绪，不能只下载桌面后就登记安装完成。图标使用矢量母版确定性生成，不使用无法调用的内置图像生成工具或未经用户选择的收费 API。

### 自动安装分区规则（用户追加）

- 新安装优先当前用户可读写、可用空间至少 25 GiB 的非 C 固定分区，按剩余空间排序，无需提权。仅有 C 固定分区时才使用 LocalAppData/Programs/VoxCPMStudio。
