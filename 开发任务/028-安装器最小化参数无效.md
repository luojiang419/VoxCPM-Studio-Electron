## 根因与修改

- 最小化会触发零尺寸 Resize。安装器 `LayoutButtons` 无条件生成窗口圆角 Region，`GraphicsPath.AddArc` 对零尺寸报“参数无效”；更新/修复 `LayoutContent` 还会按零宽度生成零字号字体。UI 线程弹错与后台安装任务继续运行可以同时发生。
- `bootstrap/Program.cs`、`updater/Program.cs` 在最小化或客户区无效时跳过布局/绘制，保留上次有效控件位置与 Region；窗口恢复后由 Resize 重新布局。没有改动安装取消、下载或完成握手逻辑。
- `builds/minimize-validation/root-cause/result.log` 保存零尺寸 AddArc 与零字号 Font 的实际异常和堆栈。修复前真实窗口回放触发未处理异常；修复后同一窗口测试通过。
- `bootstrap/MinimizeTests.cs` / `scripts/test_minimize.py` 覆盖安装器五状态×浅深主题、更新/修复窗口浅深主题，分别通过实际最小化按钮与系统窗口状态往返 3 次。额外运行限速本地 HTTP 下载，窗口最小化期间 UI 进度持续更新，最终文件 SHA256 正确。
- 既有安装集成测试最初命中真实 `D:/Program Files/VoxCPMStudio` 的安装标记，触发原本正确的续装容量豁免，导致“不可用分区通过”的夹具失败。仅将该断言改用唯一测试路径；没有修改产品容量规则或用户安装记录，随后 26 项全部通过。
