# EE2X 统一授权中心 · 方案2交互演示

石墨深灰、顶部导航、用户列表与右侧授权操作。此工程独立于正式JVOX软件，使用本地虚构数据演示流程，不提供真实身份认证、密钥签发、支付或设备限制。

## 体验流程

1. 用户授权页选择用户，勾选已核实付款，填写备注，点击确认开通；用户端与操作记录同步更新。
   同页“调整试用期限”可指定北京时间到期时刻、延长7天/一个月、立即结束或恢复过期账户；需填写原因，审计保留调整前后时间。永久授权不显示此入口。
2. 顶部“客户端演示”进入账户页，可以查看正常试用、最后一周、到期和永久状态。账户实际状态保留后台开通结果，状态预览不改变它。
3. “体验注册”创建演示账户，自动生成一个自然月试用。用户名、邮箱重复会提示；登录不会延长试用。
4. “软件接入”添加第二款软件；客户端切换该软件并领取试用。第一款软件的永久权限不会传递到第二款。
5. “设置”填写作者联系方式，客户端购买弹窗同步展示。不要输入真实密码，演示不保存或校验密码。
6. 页脚“重置演示”可恢复五个示例账户。状态存储于本浏览器localStorage，清除浏览器数据将删除演示改动。

时间锚点为北京时间2026-10-25，匹配已选设计稿；客户端倒计时在页面运行期间每秒更新。生产版必须使用服务器时间，不能照搬演示时钟或localStorage作为授权依据。
