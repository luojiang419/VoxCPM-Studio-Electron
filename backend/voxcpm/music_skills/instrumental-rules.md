# JVOX 纯音乐创作规则

纯音乐开关是最高优先级的创作模式约束。instrumental=true 时，已有歌词仅作主题背景，旧需求或旧稿中的歌手、演唱、合唱、吟唱、哼唱、说唱、口白与声线要求全部失效，不改写成无词人声。lyrics 必须为 ""，metadata.language 为 unknown。不得为了匹配参考模板添加人声。

同次完成自然中文 captionZh 和等义专业英文 caption，以具体可听见的音乐设计表达画面，不堆砌“高级、震撼、唯美”等空泛词：

1. 提炼主题、用途和情绪弧线，用少量兼容风格明确音乐身份；地域风格采用具体乐器、调式色彩、装饰音和节奏表达，避免刻板堆砌。
2. 指定一件主奏与两至四类支撑声部，交代主旋律动机如何重复、变奏和交接。尊重用户要求的独奏或极简编制，不强加复杂配器。
3. 说明奏法、音域、音色与空间：如气声质感的笛管、拨弦轮奏、低音持续音、弦乐长弓，解释声部间的呼应与留白。乐器气息不等于人声。
4. 按用户时长设计开场、主题展开、对比或高潮、回归和尾声；用乐器进入、节奏密度、力度和音区变化推动情绪。短段只保留必要发展，明确自然收束或用户要求的循环接点，不机械套用主歌/歌词副歌结构。
5. 速度、拍号、调式和时长与参数一致；未指定时可由音乐逻辑推断。中英文逐项对应，避免互相矛盾的律动与配器要求。
6. 英文明确 Fully instrumental; no vocals, singing, choir, humming, chanting, rap or spoken words，中文明确“全器乐，无人声”。这是排除条件，不写任何正向人声细节。

模型适配：

- ACE：caption 用紧凑但完整的专业英文，围绕主奏、律动、质感与结构；精确 BPM 放 metadata，不重复写入 caption。应用自动使用 [Instrumental] 歌词标记及 unknown 语言。
- MiniMax：保留 Global Metadata、Vocal Details、Arrangement 三段；Vocal Details 只声明无人声及禁止演唱/哼唱/合唱等，不描述歌手；中文对应整体风格、人声细节、编曲发展。参考只借用器乐、音色与发展维度，不继承参考中的演唱要求。
- YuE2：caption 是连贯英文风格描述，包含具体主奏及旋律发展，速度与拍号由应用合并；不输出 ABC、音符事件或流程指令，原谱由 YuE2 规划器创作，应用自动把 Vocal 旋律移到 Ins，校验后生成。
- HeartMuLa：caption 是简洁小写逗号分隔英文标签，优先 instrumental、风格、主奏、伴奏、情绪、律动、空间与制作质感，不输出段落散文或人声标签；captionZh 为对应中文标签。歌词字段为空。
