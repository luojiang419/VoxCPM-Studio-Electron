# Windows 结束进程竞态与退出偏好

表现：工作台增加关闭询问/后台运行后，安装器验收已完成安装、修复和正常复检，最后清理隔离进程偶发报 WinError 5 权限不足；再次枚举时目标进程已全部消失。

根因：修复器先向同目录窗口发送关闭消息，超时后强制结束已核实归属的主进程。父进程退出会带动 Electron 子进程结束；紧接着对处于结束阶段的子进程调用 Windows `TerminateProcess`，即便有足够权限，也可能返回 `ERROR_ACCESS_DENIED`，且进程句柄此刻尚未变为已结束状态。立即再次查询会误判为真正的权限不足。

解决：`repair/engine.py` 在终止失败后立即保存系统错误码；仅对错误码 5 等待同一已验证进程句柄最多 5 秒。句柄确认结束才接受成功，仍在运行则继续报告权限错误。保持路径、创建时间、归属目录校验与保留用户数据的边界，不按 PID 重开句柄、不吞掉权限失败。

验证：`tests/test_legacy_repairer.py` 覆盖句柄最终结束成功与仍未结束拒绝；与安装器离线测试合计 28 项通过。最终安装器实测记录见任务 `开发任务/036-退出偏好与主题确认弹窗.md`。
